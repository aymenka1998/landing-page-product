# منتج صفحة الهبوط ولوحة التحكم

لوحة عربية لإدارة المنتج دون تعديل ملفات الكود. النسخة المحلية تُفتح من الهاتف على شبكة Wi‑Fi نفسها؛ أما نسخة Vercel فتُفتح من أي شبكة باستخدام كلمة المرور.

## تشغيل لوحة Vercel مع Supabase

لجعل لوحة التحكم المنشورة تعمل من أي مكان وتحفظ التعديلات والصور على الإنترنت، اتبع [إعداد Supabase](SUPABASE_SETUP.md). يبقى التشغيل المحلي موضحاً أدناه.

إذا كنت تجهز نسخة مستقلة لمشترٍ، استخدم [قائمة تسليم الحزمة لكل عميل](SELLER_READINESS.md) مع [إعداد Google Sheets للطلبات](GOOGLE_SHEETS_ORDERS_SETUP.md).

## الإعداد مرة واحدة

1. أبقِ مجلدي `product-landing` و`product-dashboard` متجاورين.
2. ثبّت Node.js LTS وGit for Windows. أثناء تثبيت Git اختر إتاحته لبرامج أخرى (PATH).
3. ثبّت GitHub Desktop وسجّل الدخول. أضف مجلد `product-landing` كمستودع محلي وانشره إلى GitHub من التطبيق.
4. سجّل الدخول إلى Vercel، واستورد المستودع من GitHub. لإظهار الطلبات داخل اللوحة، اتبع [إعداد Google Sheets للطلبات](GOOGLE_SHEETS_ORDERS_SETUP.md) وأضف متغيري الربط في Vercel، ثم انشر الموقع.
5. انقر مرتين على `setup.bat`. يثبت الاعتمادات وينشئ شهادة HTTPS محلية للحاسوب.
6. انقر مرتين على `start-product.bat`. تظهر نافذة تشغيل فيها رمز إعداد أول حساب. افتح `https://localhost:4000` على الحاسوب، وأنشئ اسم المستخدم وكلمة المرور باستخدام الرمز. كلمة المرور 12 حرفاً على الأقل.

## تثبيت التطبيق

- **الحاسوب:** افتح اللوحة في Chrome أو Edge، ثم اختر **تثبيت التطبيق** أو أيقونة التثبيت في شريط العنوان.
- **Android:** انسخ الشهادة العامة `public/local-dashboard-root.cer` إلى الهاتف وثبّتها من إعدادات الأمان كشهادة CA. بعد ذلك افتح عنوان الحاسوب الذي يظهر في شاشة الدخول بمتصفح Chrome، ثم اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
- **iPhone:** أرسل ملف الشهادة العامة إلى الهاتف وثبّت ملف التعريف من الإعدادات. فعّل الثقة له من **الإعدادات → عام → حول → إعدادات الثقة بالشهادات**. بعدها افتح عنوان الحاسوب في Safari واختر **مشاركة → إضافة إلى الشاشة الرئيسية**. توضح [تعليمات Apple](https://support.apple.com/en-us/102390) ضرورة تفعيل الثقة للشهادة المثبتة يدوياً.

الشهادة المولدة محلية ومخصصة لهذه الشبكة. لا ترسل ملف `.dashboard-server.pfx` أو `.dashboard-https.json` لأحد. ملف `local-dashboard-root.cer` شهادة عامة مطلوبة ليثق الهاتف باتصال HTTPS.

## الاستخدام اليومي

1. على الحاسوب شغّل `start-product.bat` واتركه يعمل.
2. افتح اللوحة المثبّتة أو عنوان `https://اسم-الحاسوب.local:4000` من الهاتف على Wi‑Fi نفسها.
3. سجّل الدخول، وعدّل النصوص والأسعار والمدن والصور والمميزات والأسئلة، ثم احفظ.
4. اضغط **🚀 نشر الموقع** لإرسال التغييرات إلى GitHub؛ ينشر Vercel النسخة الجديدة تلقائياً.

جلسة الدخول تنتهي بعد 8 ساعات، وبعدها يلزم تسجيل الدخول مجدداً. إذا نسيت كلمة المرور، أوقف اللوحة، احذف `.dashboard-auth.json` من مجلد لوحة التحكم ثم أعد تشغيلها لإنشاء حساب جديد برمز جديد.

## حل المشاكل الشائعة

- **الهاتف لا يفتح العنوان:** تأكد أن الهاتف والحاسوب على Wi‑Fi نفسها، وأن نافذة اللوحة مفتوحة. استخدم اسم الحاسوب المعروض في شاشة الدخول.
- **تحذير الشهادة:** ثبّت `local-dashboard-root.cer` على الهاتف وثق بها. في iPhone فعّل الثقة الكاملة من إعدادات الشهادات.
- **فشل النشر:** تحقق من إعداد GitHub Desktop وVercel ومصادقة Git على الحاسوب.
- **الصورة مرفوضة:** ارفع JPG أو PNG أو WebP بحد أقصى 5MB.
